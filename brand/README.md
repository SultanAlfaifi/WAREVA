# هوية واريفا

المرجع الكامل للهوية في نظام التصميم على Claude: <https://claude.ai/artifact/SbsbXLk3rNHajJckZuoFnW>. يشمل قواعد الاستخدام، والألوان بالوضعين، والخطوط، والمكونات.

| الملف | الاستخدام |
|---|---|
| `tokens.json` | الرموز (الألوان والخطوط والمسافات والزوايا)، نفس رموز نظام التصميم |
| `tokens.css` | متغيرات CSS بالوضعين الفاتح والداكن، مولّدة من `tokens.json` |
| `components.css` | مكونات اللوحة والموقع: شارة الحالة، وبطاقة الحساس، وحالة الصمام، والأسباب، والسجل، والأزرار |
| `logos/`&lrm; | الشعار بأشكاله، مسارات SVG لا تحتاج الخط |
| `icons/`&lrm; | ثماني أيقونات بلون `currentColor` |
| `fonts/`&lrm; | Alexandria وReadex Pro وIBM Plex Mono، برخصة SIL Open Font License |

## قواعد سريعة

- الاسم: «WAREVA» بأحرف لاتينية كبيرة، و«واريفا» بالعربية.
- الحرف V في WAREVA والفاء في «واريفا» بلون `verify`. لا يُلوّن غيرهما.
- في الشعار المركّب يكون سطر «واريفا» بعرض WAREVA، ممدودًا بالكشيدة بين الياء والفاء وبين الفاء والألف.
- كل حالة تظهر بكلمتها وأيقونتها، لا باللون وحده: «يُسمح بالري»، «محتجز»، «استعداد»، «غسيل عكسي».
